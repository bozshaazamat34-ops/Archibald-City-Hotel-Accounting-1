# Hotel-Revenue-and-Profit-Calculator

This project was created to simplify hotel revenue and profit calculations for accommodation providers and hospitality businesses. The application helps calculate the total income from reservations based on the number of nights, guests, price per night, payment method, and selected currency. The main goal of the project is to automate financial calculations and provide a clear overview of estimated net profit.

The application automatically converts foreign currencies into Czech Koruna (CZK) using a real-time exchange rate API. It also calculates DPH (VAT tax) and applies transaction fees for Visa and Mastercard payments. This allows hotel staff or property owners to better understand operational costs and final earnings from reservations.

The project is designed as a localhost web application focused on business operations, hospitality management, and financial analytics. It can be further expanded with features such as reservation history, dashboards, booking analytics, and invoice generation.
